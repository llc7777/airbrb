1. Differentiated Styling for Navigation Buttons:
   Each navigation button uses a distinct styling pattern to make sections easier to distinguish and improve overall clarity.

2. Snackbar-Based Error Handling:
   All alerts were replaced with Snackbar components to deliver non-intrusive and consistent feedback across pages.

3. Booking Status Visualization in Landing page lists:
   Color-coded highlights and status chips allow users to instantly recognize the state of each booking.

4. Confirmation Dialogs:
   Destructive actions include confirmation dialogs to prevent accidental deletion or cancellation.

5. Notification Badge & Color-Coded Alerts:
   The notification button shows a small numeric badge for unread alerts, and each alert type is color-coded, green for accepted bookings, red for declined bookings, and yellow for new booking requests.

6. Hover Elevation for Listing Cards:
   Listing cards slightly lift on hover to provide clear visual feedback and help users see which item they are selecting.

7. Dynamic Navigation Titles:
   Each page displays a dynamic navigation title so users always know which page they are currently on.

8. Toggle-Based Media Input with Dynamic Helper Text:
   The listing creation page uses a toggle to switch between image and YouTube link inputs, updating the helper text accordingly so users clearly understand which type of link to provide.

9. Sorted Booking History on Listing Detail Page:
   The listing detail page displays all of a user's bookings, automatically sorted by date and status to make the information easier to understand.

10. Clear Helper Text for All Input Fields:
    Helper text is applied across input fields throughout the app to clearly guide users on what values they need to enter.
