1. Semantic HTML Structure:
   The app uses proper semantic HTML and clear heading structures so screen readers can navigate content logically.

2. Keyboard Navigation:
   All interactive elements support full keyboard navigation with logical tab order and proper focus management.

3. Alternative Text and Image Accessibility:
   All images include descriptive alternative text and meaningful fallbacks so screen readers can accurately convey visual content.

4. Form Validation and Error Messages:
   Forms provide clear labels, helper text, and descriptive error messages announced via accessible Snackbar alerts.

5. Navigation and Wayfinding:
   Consistent navigation layouts and clear page titles help users understand where they are at all times.

6. Color Contrast and Visual Design:
   All text and UI elements follow WCAG AA color contrast standards and never rely on color alone to convey meaning.

7. Responsive and Scalable Design
   Font sizes, layouts, and touch targets scale responsively to ensure usability across zoom levels and mobile devices.

8. Content Structure and Readability
   Text hierarchy, spacing, and descriptive button/link labels improve readability and reduce cognitive load.
